📚 Cybersecurity Learning Center

What is HTTPS?

HTTPS encrypts the connection between your browser and a website. However, scammers can also use HTTPS, so the padlock alone does not prove a website is trustworthy.

What is a domain?

A domain is the readable name used to reach a website, such as example.com. DNS helps browsers find the relevant server addresses.

How can you spot a suspicious link?

  • Look carefully for misspellings in domain names.
  • Be cautious of unexpected requests for money or passwords.
  • Avoid downloading unexpected files.
  • Verify important messages using a separate trusted channel.
